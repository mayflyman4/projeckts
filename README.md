# Projeckts

Small experiments, demos, and mini-apps — static HTML, no build step. Open `index.html` to browse all projects, or jump straight into one below.

## Projects

- **[Hello World](projects/helloworld/)** — simple starter project with a friendly greeting.
- **[Money Lens](projects/moneylens/)** — upload a CSV and see where your money went.
- **[Lern Deutsch](projects/learn-german/)** — A1 German flashcards, tag-filtered exercises with score tracking. Exercises live under `exercises/<tag>.yaml`; `a1-wortliste.txt` is the official Goethe A1 word list used to keep vocabulary at the right level.
